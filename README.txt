PACE GAMING KPI V76 - PAGE 2 / NEW PLAYERS ADDED BY EXECUTIVE

THIS IS AN UPDATE KIT, NOT THE COMPLETE KPI SYSTEM.

Because the current V75 KPI ZIP was not attached in this conversation, this kit
patches your existing downloaded V75 ZIP. It does not replace your tracker.

WHAT THE UPDATE DOES
- Adds a New Players Added by Executive section on page 2 of each separate
  Month vs Month PDF, below the existing booking / Theo / W-L performance table.
- Uses DL, KA, SP, CV, LR, TF, KH and their existing manual name/count entries.
- Includes the current comparison month's counts and an overall total.
- Player names never appear in the PDF.
- Keeps your current Complete PDF, comparisons, report history and email exports.

HOW TO APPLY (ON A COMPUTER WITH PYTHON INSTALLED)
1. Download your original Pace Gaming KPI V75 ZIP from the earlier message.
2. Place that ZIP and this unzipped update kit in the same folder.
3. Open Terminal / PowerShell in this folder, then run:
       python apply_update.py "Pace_Gaming_KPI_System_v75_Manual_New_Player_Names.zip"
4. The updater creates a separate ..._V76_New_Players_Page_2.zip file.
5. Extract the new ZIP and open index.html as before.

OR: Upload your original V75 ZIP into this chat to have it integrated here.

TECHNICAL NOTES
This is a drop-in, non-destructive extension loaded by index.html. It enriches
Booking Executive comparison tables in the browser and before print/export.
The existing V75 localStorage keys are read, but no player records are uploaded,
transmitted, or written by this extension.

EASIER WINDOWS OPTION (NO PYTHON REQUIRED)
1. Unzip this V76 update kit.
2. Double-click Apply_KPI_V76_Update_Windows.bat.
3. Select your downloaded V75 KPI ZIP in the file picker.
4. A NEW updated V76 ZIP will appear beside your original V75 ZIP.
5. Extract it and open index.html.

This update was verified on a representative page-2 layout, not against the
original V75 ZIP, which must be selected by the user.
